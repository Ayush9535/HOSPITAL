# Support

Thanks for using the Hospital Management System. Here's how to get help.

## Before you ask

1. Read the [README](README.md) and the docs under [`docs/`](docs/).
2. Search [existing issues](https://github.com/axonxmedtech/HOSPITAL/issues) —
   your question may already be answered.

## How to get help

| I want to… | Do this |
| ---------- | ------- |
| Report a **bug** | Open a [Bug Report](https://github.com/axonxmedtech/HOSPITAL/issues/new?template=bug_report.yml) |
| Request a **feature** | Open a [Feature Request](https://github.com/axonxmedtech/HOSPITAL/issues/new?template=feature_request.yml) |
| Report a **security vulnerability** | Follow the [Security Policy](SECURITY.md) — **do not** open a public issue |
| Ask a **usage / how-to question** | Open a [GitHub Discussion](https://github.com/axonxmedtech/HOSPITAL/discussions) *(enable Discussions if not already on)* |
| Contribute code | Read [CONTRIBUTING.md](CONTRIBUTING.md) |

## Response expectations

This is maintained by a small team. Issues are triaged on a best-effort basis;
security reports are prioritised. For commercial / SLA-backed support, contact
`TODO@axonxmedtech.example` *(replace with your real support contact)*.

## Please never post

- Real patient data (PHI), or any personally identifiable information
- Passwords, JWTs, API keys, `.env` contents, or database credentials

Redact these from logs and screenshots before attaching them.
